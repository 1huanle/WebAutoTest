# 结束透析自动化设计

## 目标

在现有主写入流程完成双人核对后，自动执行结束透析。

## 数据

`data/main_write.yaml` 新增 `end_dialysis`：

- `off_machine_nurse`: `陈奕源`
- `blood_return_flow`: `5`

结束时间由页面自动生成，自动化不读取、不填写也不覆盖该字段。

## 页面交互

1. 在透析单页面点击顶部“结束透析”。
2. 等待标题为“结束透析”的 Layui iframe 弹窗。
3. 选择下机护士，填写回血流量。
4. 点击弹窗内“确认”，等待该弹窗和其遮罩关闭。

## 代码边界

- 新增 `EndDialysisDialog`，复用现有 `LayuiIframeDialog` 的打开和关闭处理。
- `DialysisSheetPage` 只负责打开该弹窗。
- `tests/main_write.py` 只负责按 YAML 编排调用。

## 错误处理与验证

- 弹窗未关闭会由现有等待断言报错，中断主流程。
- 单元测试使用弹窗模拟页面，验证点击、下机护士选择、回血流量填写、结束时间不被改写和确认关闭。
- 流程测试验证结束透析处于双人核对之后。
