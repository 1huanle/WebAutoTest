# 开始透析穿刺点位提示处理设计

## 目标

开始透析弹窗保持“穿刺点位”不填写。点击底部“确认”后，如果 iframe 内出现“穿刺点位信息未填写，是否继续保存？”提示，自动点击该提示层内的“确定”，然后等待开始透析弹窗及所属遮罩关闭。

## 组件边界

提示层属于“血液透析 > 开始透析 > 穿刺点位未填写”，由 `StartDialysisDialog` 内部处理，不创建全局确认按钮工具，也不复用透析处方的医嘱推送弹窗。

## 定位与交互

1. 点击开始透析 iframe 底部精确名称为“确认”的按钮。
2. 在同一 iframe 内查找可见的 Layui 提示层，并用“穿刺点位信息未填写”文本限定范围。
3. 如果提示层出现，点击其内部精确文本为“确定”的最后一个可见元素。
4. 不勾选“不再提示”。
5. 等待外层开始透析弹窗及与其 `times` 对应的遮罩关闭。

## 测试策略

扩展本地 iframe 测试夹具：第一次点击开始透析“确认”只显示穿刺点位提示层；点击提示层“确定”后才关闭外层弹窗和遮罩。测试同时保留一个无关“确定”按钮，证明定位范围不会误点。

## 范围边界

- 不填写穿刺点位。
- 不勾选“不再提示”。
- 不修改开始透析 YAML 数据。
- 不自动运行会保存真实患者数据的 `tests/main_write.py`。
