# 直接写入透析处方测试设计

## 目标

新增一条真实写入测试：在透析单中点击透析号 `21000536543` 选择患者“陈奕源测试”，按指定测试数据填写透析处方、选择医生“陈奕源”，并点击“确认”保存。

## 数据与范围

- 测试数据文件：`data/dialysis_prescription_data.yaml`。
- 患者标识：姓名“陈奕源测试”，透析号 `21000536543`。
- 处方数据采用用户提供截图中的当前值，包括机号 `58-1`、抗凝剂“叶酸片”、透析方式 `HD`、透析时长 `4`、处方脱水量 `1`、首剂 `4000`、维持 `3`、血流量 `225`、透析液流量 `501`、医生“陈奕源”等可编辑字段。
- 测试不新增、删除或执行临时医嘱，仅更新并确认透析处方。

## 实现

`DialysisSheetPage` 新增按透析号选择患者的方法，使用患者列表中精确的透析号链接点击选中记录。`PrescriptionSection` 新增填写处方、选择医生、确认保存和读取确认状态的方法；定位器先通过可视化页面的实际 `name`、`id`、标签或下拉选项确认，避免依赖截图坐标。

测试用例读取 YAML 数据，完成“选择患者 -> 填写处方 -> 选择医生 -> 确认”的顺序操作，并断言确认状态已变化。该用例不添加跳过标记，运行时会写入真实系统数据。

## 验证

先运行该用例确认其因 POM 接口不存在而失败；完成实现后运行同一用例，检查处方确认状态。最后运行完整 pytest 回归；完整回归需要指定可写的 `--basetemp C:\tmp\webtest-pytest-*`。
