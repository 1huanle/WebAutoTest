# 单一登录用例设计

## 目标

将登录功能测试收敛为一条端到端用例，减少与完整登录流程重复的页面加载及账号密码填写测试。

## 变更范围

- 删除 `tests/test_login_page.py`。
- 保留 `tests/test_login_flow.py::test_login_redirects_to_the_success_page`，该用例验证账号输入、密码输入、登录提交、角色选择及跳转到透析管理页面。

## 非变更项

- 保留配置测试、运行入口测试和报告生成测试。
- 不修改登录页面对象、账号数据、浏览器无头模式或操作速度。

## 验证

运行保留的登录流程用例，并确认测试收集结果中仅保留一条登录业务用例。
