# 透析单分区 POM 设计修订

## 结论

主任角色的透析单页面已直接包含血液透析业务分区：透析处方、透前评估、临时医嘱、双人核对、监测记录、透后评估和治疗小结。页面对象应围绕该单页分区组织，而非以患者管理页面作为前置入口。

## 结构

- `DialysisSheetPage`：血液透析透析单的页面入口，负责排班日期、患者搜索、患者列表和选中患者上下文。
- `PrescriptionSection`：透析处方区域的只读字段、确认状态和可见操作。
- `PreDialysisAssessmentSection`：透前评估区域的只读字段、确认状态和可见操作。
- `TemporaryOrdersSection`：临时医嘱区域的表格、可见操作和只读医嘱查询；默认测试不调用新增、执行或删除。
- 其余分区按相同模式逐批增加，不与 CRRT 或其他一级模块共用业务定位器。

所有类均定义 `MODULE_NAME = "血液透析"`，并在类、定位器分组及公开方法使用中文注释。分区组件接收当前 `Page`，由 `DialysisSheetPage` 的只读属性创建，避免测试直接操作 DOM。

## 测试边界

先验证每个分区可见、分区标题正确、只读字段和表格可读取；涉及新增、确认、执行、删除、签名和打印的医疗数据写入操作，只在显式授权的独立测试中实现和调用。
