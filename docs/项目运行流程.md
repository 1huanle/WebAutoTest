# 项目运行流程

## 1. 环境准备

项目使用 Python、pytest 和 Playwright 执行 Web 自动化测试。建议在项目根目录使用虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m playwright install chromium
```

如果 PowerShell 不允许执行激活脚本，可直接使用虚拟环境中的 Python：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

## 2. 配置测试环境

复制 `.env.example` 为 `.env`，再根据实际环境调整配置。`.env` 已被 Git 忽略，适合保存本机参数。

```powershell
Copy-Item .env.example .env
```

常用配置项如下：

| 配置项 | 作用 | 默认值 |
| --- | --- | --- |
| `BASE_URL` | 透析管理页面地址 | `https://yunjingzhi.com/yunjingservice/user/txform.shtml` |
| `TEST_ENV` | 当前目标环境（`online`、`test`、`pre`） | `online` |
| `BROWSER` | Playwright 浏览器类型 | `chromium` |
| `HEADLESS` | 是否无界面运行 | `true` |
| `RECORD_VIDEO` | 是否录制测试视频 | `false` |
| `DEFAULT_TIMEOUT` | 控件操作超时，单位毫秒 | `30000` |
| `NAVIGATION_TIMEOUT` | 页面导航超时，单位毫秒 | `60000` |

登录流程测试使用 `data/pc/login_data.yaml` 中的账号、密码和角色；该文件不应写入真实生产凭据。

## 3. 执行测试

在项目根目录执行以下命令：

```powershell
# 使用项目入口运行完整测试集
.\.venv\Scripts\python.exe run.py

# 运行线上环境
.\.venv\Scripts\python.exe run.py --target-env online

# 运行测试环境
.\.venv\Scripts\python.exe run.py --target-env test

# 运行预发布环境
.\.venv\Scripts\python.exe run.py --target-env pre

# 只运行主流程，并指定测试环境
.\.venv\Scripts\python.exe run.py --target-env test tests/pc/main_write.py

# 直接运行完整测试集
.\.venv\Scripts\python.exe -m pytest

# 运行配置回归测试
.\.venv\Scripts\python.exe -m pytest tests/pc/test_config.py::test_default_base_url_matches_dialysis_management_page -v

# 运行登录页面冒烟测试
.\.venv\Scripts\python.exe -m pytest tests/pc/test_login_page.py -m smoke -v
```

可通过命令行覆盖部分配置：

```powershell
.\.venv\Scripts\python.exe -m pytest --browser chromium --env dev
```

## 4. 查看测试产物

- Allure 原始结果：`reports/allure-results/`。
- 失败截图：`reports/screenshots/`。
- 启用 `RECORD_VIDEO=true` 后的视频：`reports/videos/`。
- 执行日志：`logs/`。

生成并打开 Allure HTML 报告：

```powershell
.\.venv\Scripts\python.exe generate_report.py
```

报告脚本使用项目内 `tools/allure-2.44.1/` 的 Allure Commandline。执行后会生成 `reports/allure-report/index.html`，并自动在浏览器中打开报告。

## 5. 当前运行限制

登录页面测试需要访问 `https://yunjingzhi.com`。当前受限运行环境可能返回 `net::ERR_NETWORK_ACCESS_DENIED`，这会导致依赖真实页面访问的用例失败。配置测试不访问外网，可用于快速确认本地配置是否正确。

## 6. 保存并复用登录状态

首次登录或登录态过期时，运行以下命令。浏览器打开后，手动完成登录和角色选择，进入透析管理页后回到终端按回车：

```powershell
.\.venv\Scripts\python.exe save_login_state.py
```

脚本会将 Cookie 和 localStorage 保存为 `auth/storage_state.json`。该文件等同于登录凭证，已加入 Git 忽略规则，不能提交、复制或分享。后续测试会自动加载它；唯一的登录流程用例会主动跳过该状态，以继续验证完整登录过程。

登录态过期时，删除 `auth/storage_state.json` 后重新运行保存脚本。
